Quickstart

Install, run a smoke test, and explore the YAML-driven experiment runner
QUICKSTART
STEP 1

Install

FedRF-Distill targets Python ≥ 3.10. scikit-learn is a hard dependency; XGBoost, LightGBM, and CatBoost are optional extras.

# Clone
$ git clone https://github.com/<you>/fedrf-distill.git
$ cd fedrf-distill

# Create a venv (Python 3.10+)
$ python3.13 -m venv .venv && source .venv/bin/activate

# Core install (sklearn-only)
$ pip install -e .

# Full install — all four tree backends
$ pip install -e .[xgboost,lightgbm,catboost]
Why optional extras? Hook B's headline claim — “every client picks its own backend” — works with just sklearn. The extras unlock the cross-framework ablation in the paper.
STEP 2

Run the smoke test

Verifies the entire pipeline on Breast Cancer in < 1 minute. Trains 10 federated clients with the default proxy-redistillation aggregator and Laplace DP.

$ python -m experiments.scripts.run_experiment \
    --config experiments/configs/breast_cancer_heterogeneous.yaml \
    --rounds 2 --out runs/smoke

# expected output
# [round 0] acc=0.78 F1=0.74 bytes=12,535 eps=2.5 t=0.6s
# [round 1] acc=0.86 F1=0.83 bytes=13,655 eps=5.0 t=0.4s
# wrote runs/smoke/metrics.jsonl, runs/smoke/privacy_ledger.jsonl
STEP 3

Anatomy of an experiment

One YAML file fully describes a federation run. Every plug-replaceable component is selected by string.

# experiments/configs/adult_dp_gaussian.yaml
data:     {name: adult, seed: 42}
partition: {name: dirichlet, alpha: 0.5, n_clients: 10}
proxy:    {source: held_out, n: 2000}
model:
  teacher_framework: sklearn_rf
  student_framework: sklearn_dt
distillation:
  mode: argmax_weighted
  temperature: 1.0
dp:
  mechanism: gaussian
  epsilon: 1.0, delta: 1.0e-5
  accountant: rdp, target_budget: 5.0
aggregator: {name: proxy_redistillation}
meta:       {name: stacking}
training:   {n_rounds: 5}

To swap an aggregator, change one line: aggregator.name: "confidence_weighted".

STEP 4

Hook B — mix frameworks across clients

Set model.frameworks_per_client to a list. The runner cycles through it.

model:
  teacher_framework: sklearn_rf     # default for non-listed clients
  student_framework: sklearn_dt     # student always sklearn — wire-stable
  frameworks_per_client:
    - sklearn_rf
    - xgboost
    - lightgbm
    - catboost
  # round-robins across the K clients
What the coordinator sees: framework-agnostic ClientUpdate blobs. The audit field framework lets you log a per-round mix heatmap (e.g. 4× sklearn, 3× xgb, 2× lgbm, 1× cb).
STEP 5

Programmatic API

For unit-style experiments, skip the YAML and instantiate the config directly.

from fedrf_distill.config.schema import ExperimentConfig
from fedrf_distill.orchestration.runner import ExperimentRunner

cfg = ExperimentConfig.model_validate({
    "data": {"name": "adult", "seed": 42},
    "partition": {"name": "dirichlet", "alpha": 0.5, "n_clients": 10},
    "dp": {"mechanism": "gaussian", "epsilon": 1.0, "delta": 1e-5},
    # …everything else takes a sensible default…
})

runner = ExperimentRunner(cfg)
result = runner.run(n_rounds=5)

print(result.history[-1])    # last-round metrics
print(result.ledger.cumulative())  # (ε_cum, δ_cum)
STEP 6

Run the 480-cell benchmark sweep

Reproduces every cell in the paper. Output: a single CSV; ~6 h on a 16-core box.

$ python -m experiments.scripts.run_benchmark_sweep \
    --datasets all \
    --partitions iid dirichlet_0p5 dirichlet_0p1 pathological_2 \
    --dp null laplace_5 gauss_1 gauss_0p5 \
    --frameworks all-sklearn mixed-4 all-xgb \
    --seeds 3 --rounds 5 \
    --out results/benchmark_sweep.csv
STEP 7

Empirical privacy audit

Yeom-style Membership Inference Attack on a single client surrogate.

from fedrf_distill.privacy.attack import membership_inference_attack

mia = membership_inference_attack(
    surrogate    = client.surrogate,
    member_set    = (X_local, y_local),
    nonmember_set = (X_test,  y_test),
)
print(mia)
# MIAResult(auc=0.572, advantage=0.143, tpr_at_low_fpr=0.061)
How to read MIAResult: An AUC near 0.5 means the surrogate is empirically privacy-safe — the adversary does no better than chance. See Diagram 10 for the full ROC sweep across ε.
