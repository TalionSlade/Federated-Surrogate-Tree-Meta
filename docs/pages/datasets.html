The 10 datasets at a glance

Sourced from the UCI repo (via OpenML mirrors) and scikit-learn. Loaders live in fedrf_distill.data.loaders.

Adult binary 48,842 14 2 OpenML id 1590 The canonical tabular-FL benchmark. Mixed numeric + categorical, mild class imbalance, mature literature for direct comparison.
Bank Marketing imbalanced 45,211 16 2 OpenML id 1461 88/12 class skew. Tests aggregator behaviour when one class is rare in some shards under Dirichlet partitioning.

Diabetes (Pima) binary 768 8 2 OpenML id 37 Healthcare domain — naturally federated across hospitals. Small-n pairs well with strong DP (ε ≤ 1).
HIGGS binary 100,000 28 2 OpenML id 23512 (subset) Large-n flagship. Demonstrates FedRF-Distill scales beyond toy data without runtime regressions.

Mushroom binary 8,124 22 2 OpenML id 24 Fully categorical features. Validates CatBoost adapter's native factor handling — a Hook B success criterion.
NSL-KDD multi · 5 148,517 41 5 KDDCup99 successor Cybersecurity / network intrusion detection. Genuinely federated in practice — privacy-sensitive enterprise data.

Why these ten?

The set was assembled to maximise diversity along four axes simultaneously:

  • Scale: 569 rows (Breast Cancer) → 581 K rows (Covertype). Tests memory/time scaling.
  • Class count: 2 → 26. Stresses padding logic, especially under Pathological partitioning.
  • Class skew: from balanced (Adult) to 99.8/0.2 (Credit Card Fraud).
  • Feature type: pure numeric (HIGGS), pure categorical (Mushroom), mixed (Bank, Adult).

Every dataset is downloadable from a public source with a single function call. Loaders are cached under ~/.fedrf_distill/cache/.
