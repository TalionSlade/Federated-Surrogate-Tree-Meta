Wire format — ClientUpdate (framework-agnostic)

surrogate_blob: bytes
Pickled adapter. Coordinator never inspects the contents — only calls predict_proba via the adapter.
surrogate_class_path: str
e.g. "fedrf_distill.models.xgboost_adapter:XGBoostAdapter". Used by the safe deserialiser to reject unknown classes.
framework: str
Audit field declaring which backend ran locally. Coordinator may log a mixed-framework heatmap per round.
