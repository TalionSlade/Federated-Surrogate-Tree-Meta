Formal building blocks

Temperature scaling
$$p_i^{(T)} = \frac{p_i^{1/T}}{\sum_j p_j^{1/T}}$$
\(T > 1\) smooths the distribution to preserve "dark knowledge"; \(T = 1\) is the identity.
Laplace mechanism
$$\eta \sim \mathrm{Lap}\!\left(0,\, \tfrac{\Delta_1}{\varepsilon}\right),\; \Delta_1 \le 2$$
Pure \(\varepsilon\)-DP. \(\Delta_1\) bound because one row of \(P\) swaps at most 2 mass in \(L_1\).
Gaussian mechanism
$$\sigma \ge \frac{\Delta_2\sqrt{2\ln(1.25/\delta)}}{\varepsilon}$$
\((\varepsilon, \delta)\)-DP. \(L_2\) sensitivity \(\Delta_2 \le \sqrt{2}\). Composes tightly under Rényi-DP.

Mathematical Foundation
Why distillation works — Hinton-Vinyals view
▌ WHAT — the KD loss
The student minimises a convex combination of cross-entropy on hard labels and KL-divergence from the teacher's soft distribution.
$$p_T(i,k) = \frac{\exp(z_k/T)}{\sum_j \exp(z_j/T)}$$
$$\mathcal{L}_{\mathrm{KD}}(\theta_S) = (1-\lambda)\,\mathrm{CE}(p_S, y) + \lambda\, T^2\, \mathrm{KL}\!\left(p_T^{\,\text{teacher}}\,\|\,p_T^{\,\text{student}}\right)$$
$$\mathrm{KL}(P\,\|\,Q) = \sum_k P(k)\, \log\frac{P(k)}{Q(k)}$$
# Limits: \(T\to 1\): argmax (hard)  ·  \(T\to\infty\): uniform (max entropy)
▌ WHY — soft labels carry "dark knowledge"
A hard label says "this is a 7." A soft label says "this is a 7, but it's also slightly a 1 and not at all a 0." Those off-target probabilities encode the teacher's similarity structure over the class manifold.

Mathematically: H(P) ≥ H(argmax(P)) — soft labels have strictly more entropy, so they transmit more information per row. The student converges with the same data but to a smoother decision surface.

For DP this matters doubly: noise on soft labels degrades information gracefully; noise on a hard label flips classes outright.
▌ MINDSET — privacy first, compression second
We don't compress to save bandwidth — we compress because a smaller decision boundary leaks less. The depth-6 student is a 10 KB summary that throws away over-fitted memorisation of training rows.

The DP step is mandatory between teacher and student. Skipping it lets the student over-fit to noiseless soft labels, which is provably less private than the original raw-data baseline.

The proxy dataset is NOT private. It's a public test set we use to render comparable predictions across clients — distillation happens privately on each client's own (X, P̃).

Every symbol appearing in the Hinton-Vinyals KD objective above — what it is, where it lives, how it's computed

Symbol
What it represents
Where it lives / how it's computed
Logits & temperature softening
\(z_k\)
Teacher's pre-softmax score (logit) for class \(k\) on a given row. For tree ensembles we take log(predict_proba) as a stand-in.
distillation/soft_labels.py::_logits_from_proba — clips \(P_k\) above \(\epsilon_{\min}\) then logs it.
\(T\)
Distillation temperature. \(T = 1\) recovers the teacher's posterior; \(T \to \infty\) drives toward the uniform distribution (maximum entropy); \(T \to 0^+\) collapses to argmax (hard label).
cfg.distillation.temperature; consumed by SoftLabelGenerator.apply_temperature.
\(p_T(i, k)\)
Tempered softmax probability for row \(i\), class \(k\). Each row sums to 1 — lives on the simplex \(\Delta^{K-1}\).
Computed as softmax(z/T, axis=-1) in distillation/soft_labels.py.
\(i\)
Row index inside the client's training set \((1 \le i \le n_k)\).
Implicit batch index in numpy / sklearn calls.
\(j, k\)
Class indices in the sum \(\sum_j \exp(z_j / T)\). \(K = |\mathcal{C}|\) is the number of classes.
self.teacher.classes_ on the client; carried into ClientUpdate.classes.
The KD objective
\(\mathcal{L}_{\mathrm{KD}}(\theta_S)\)
Total student loss as a function of student parameters \(\theta_S\). A convex combination of hard-label CE and soft-label KL.
distillation/surrogate.py::SurrogateDistiller.distill — for tree students this is approximated by re-fitting on \((X, \tilde{P})\) targets.
\(\theta_S\)
Student model parameters — for a depth-\(d\) tree, the split thresholds and leaf probability vectors.
Internal state of the fitted surrogate (S_k.tree_ in sklearn).
\(\lambda\)
Mixing weight between hard-label CE and soft-label KL. \(\lambda = 0\) ignores the teacher; \(\lambda = 1\) is pure distillation.
cfg.distillation.kd_weight; default 1.0 in privacy-first mode.
\(T^2\)
Gradient-magnitude correction. Soft-label gradients shrink as \(1/T^2\); multiplying by \(T^2\) keeps the two loss terms on the same scale.
Hard-coded inside the KL-term computation per Hinton & Vinyals (2015).
\(\mathrm{CE}(p_S, y)\)
Cross-entropy between the student's prediction and the one-hot hard label.
Used only when ground-truth \(y\) is provided to the distiller; otherwise this term is dropped.
\(p_S\)
Student's predicted distribution for the row — output of \(S_k\) on \(x_i\).
S_k.predict_proba(X_local).
\(y\)
Hard label vector on the client. Only used if kd_weight < 1.
FederatedClient.y_local.
KL divergence & entropy
\(\mathrm{KL}(P \,\|\, Q)\)
Kullback–Leibler divergence — the information cost of using \(Q\) when the truth is \(P\). Asymmetric, non-negative, zero iff \(P = Q\).
In the tree-student approximation, KL minimisation reduces to fitting \(S_k\) on the teacher's soft-label targets directly.
\(P, Q\)
Two distributions over \(K\) classes. In the KD term: \(P = p_T^{\text{teacher}}\), \(Q = p_T^{\text{student}}\).
Both live on \(\Delta^{K-1}\); rows of \(\tilde{P}_k\) and \(S_k(X_k)\) respectively.
\(H(P)\)
Shannon entropy of \(P\). \(H(P) \ge H(\arg\max P)\) — soft labels strictly carry more bits per row than hard labels.
Measured for diagnostics in distillation/diagnostics.py::soft_label_entropy.
\(p_T^{\text{teacher}}, p_T^{\text{student}}\)
Tempered posteriors from teacher and student, both at the same temperature \(T\) so the KL is meaningful.
Teacher: privatised \(\tilde{P}_k\). Student: S_k.predict_proba at distil time.
Inputs that flow in from earlier stages
\(\tilde{P}_k\)
The DP-noised soft-label targets used as the KL teacher distribution. The only randomised object in the pipeline.
Output of privacy/mechanisms.py::privatize; passed to SurrogateDistiller.distill.
\(X_k\)
The client's private feature matrix — used as the support over which the soft-label/KL is averaged.
FederatedClient.X_local.
\(S_k\)
The student — a small (depth ≈ 6) tree that emerges as the minimiser of \(\mathcal{L}_{\mathrm{KD}}\).
Return value of SurrogateDistiller.distill; serialised to the wire.
Note. The KL term is what makes distillation a statistical operation rather than a structural one — that's why students fit on \((X_k, \tilde{P}_k)\) can come from any tree backend and still encode the teacher's class-similarity geometry. DP noise on soft labels degrades information gracefully; the same noise on hard labels would flip classes outright.
