Aggregation Strategies

Three plug-replaceable aggregators implementing AggregatorProtocol — same input, very different bias-variance tradeoff
DIAGRAM 13 / 18

ProxyRedistillationAggregator

name: "proxy_redistillation"
DEFAULT

The framework's signature aggregator. Average client surrogate probs on a shared proxy, then re-distill into a fresh global tree. Recovers a single coherent model.

# Average ensemble probabilities, re-distill P̄ = meank( surrogateₖ.predict_proba(proxy_X) ) G = distill(proxy_X, P̄, classes) return G # single ModelAdapter
PROS
+ Output is a fresh single tree, not an ensemble.
+ DP carries through (post-processing).
+ Resilient to a single bad client.
CONS
− Requires a proxy dataset.
− Quality bounded by proxy coverage.

ConfidenceWeightedAggregator

name: "confidence_weighted"
VARIANT

Subclass of proxy aggregator. Weights each client by its declared n_samples before averaging — large clients pull more weight.

# Weighted average then re-distill wₖ = nₖ / Σⱼ nⱼ P̄ = Σₖ wₖ · surrogateₖ.predict_proba(proxy_X) G = distill(proxy_X, P̄, classes)
PROS
+ Reflects QuantitySkew reality.
+ Smooth degradation if one client is tiny.
CONS
− Vulnerable to a tampered n_samples field.
− Less fair to small-n clients.

MajorityVoteAggregator

name: "majority_vote"
BASELINE

Classical hard-vote ensemble. Each client surrogate predicts a class; the global model returns the modal label. Kept for paper ablation.

# Hard vote — no distillation ŷₖ = surrogateₖ.predict(x) G(x) = modek(ŷₖ) return VotingEnsembleAdapter(...)
PROS
+ No proxy needed.
+ Trivially explainable.
CONS
− Discards probabilistic info.
− Output is an ensemble — bigger, slower.
− Worse under non-IID class skew.

Mathematical Foundation
Merge in label space, not weight space
▌ WHAT — proxy redistillation derivation
$K$ client surrogates each produce a row of probabilities on the proxy. The average is the row-wise barycentre in $\Delta^{K-1}$:
$\bar{P}[i] = \sum_{k=1}^{K} \gamma_k \cdot S_k.\mathrm{predict\_proba}(x_i),\quad \gamma_k \ge 0,\ \sum_k \gamma_k = 1$
$G \;=\; \arg\min_{T} \sum_{i} \mathcal{L}\bigl(T(x_i),\, \bar{P}[i]\bigr) + \alpha\,|T|$
$\mathrm{Var}(\bar{P}) \;\le\; \sum_{k} \gamma_k^2\,\mathrm{Var}(P_k) \;\le\; \dfrac{1}{K}\max_k \mathrm{Var}(P_k)$
# Privacy: $\bar{P}$ inherits $\min_k(\varepsilon_k, \delta_k)$ by post-processing
▌ WHY — re-distil, don't ensemble
A K-tree ensemble is K× the size on the wire. Re-distillation produces one final tree of ~10 KB — the same wire format as any client surrogate.

The averaged P̄ has lower variance than any single client Pk. Re-distilling on this smoother target gives a globally-better student than naive ensembling.

The output is itself a ModelAdapterProtocol — the broadcast artifact is wire-compatible with the next round's clients. Recursion works.
▌ MINDSET — three strategies, one signature
All three aggregators implement AggregatorProtocol: aggregate(updates, proxy_X, classes) → ModelAdapter. The runner sees only the protocol.

Strategy choice is empirical, not theoretical. Proxy-redistillation wins on most non-IID regimes; confidence-weighted wins under heavy quantity skew; majority-vote is the ablation baseline.

The proxy is shared across rounds. One sample, many uses. Re-sampling per round would waste epsilon if the proxy were private — but it's public.

Every symbol used in the proxy barycentre, redistillation, and variance bound — what it is, where it lives, how it's computed

Symbol
What it represents
Where it lives / how it's computed
Client surrogates & proxy domain
\(K\)
Number of clients participating in the round; the cardinality of the surrogate collection averaged on the proxy.
len(updates) in ProxyRedistillationAggregator.aggregate; set by cfg.federation.n_clients.
\(S_k\)
Per-client surrogate tree (the wire artefact) wrapping \(\mathrm{predict\_proba}: \mathbb{R}^d \to \Delta^{|\mathcal{C}|-1}\).
Deserialised from ClientUpdate.surrogate_blob via safe_deserialize; implements ModelAdapterProtocol.
\(x_i\)
A row of the public proxy feature matrix. The shared evaluation point at which every \(S_k\) is queried.
proxy_X[i] built by build_proxy_dataset in data/proxy.py (held-out / synthetic / public).
\(S_k.\mathrm{predict\_proba}(x_i)\)
Row-stochastic probability vector emitted by client \(k\)'s surrogate at proxy point \(x_i\); lives in \(\Delta^{|\mathcal{C}|-1}\).
S_k.predict_proba(proxy_X) called inside aggregation/proxy_redistillation.py.
Barycentre weights & aggregate target
\(\gamma_k\)
Non-negative simplex weight assigned to client \(k\). Uniform \(1/K\) for proxy-redistillation; confidence-derived for ConfidenceWeighted; one-hot per row for MajorityVote.
Computed in _compute_weights of each aggregator (e.g. confidence_weighted.py); defaults to np.full(K, 1/K).
\(\bar{P}[i]\)
Row-wise barycentre on the proxy — the convex combination \(\sum_k \gamma_k S_k.\mathrm{predict\_proba}(x_i)\). The redistillation target.
P_bar = np.average(stacked_probs, axis=0, weights=gammas) in proxy_redistillation.py.
\(\Delta^{K-1}\)
The probability simplex over class indices — non-negative entries summing to 1. Each row of \(\bar{P}\) and every \(S_k\) output lives here.
Enforced by the predict_proba contract on ModelAdapterProtocol and re-checked after averaging.
Redistillation objective
\(T\)
Candidate decision tree in the depth-bounded hypothesis class; the argmin variable of the redistillation objective.
Iterated over implicitly by sklearn's CART; concretised as DecisionTreeClassifier inside SurrogateTreeDistiller.
\(\mathcal{L}\)
Pointwise distillation loss between student output and target row — weighted 0-1 (Mode A) or squared error (Mode B).
Selected by cfg.distillation.mode; consumed inside SurrogateTreeDistiller.distill.
\(\alpha\,|T|\)
Complexity regulariser on the tree (proxy for max_depth, min_samples_leaf, ccp_alpha). Keeps the wire payload small.
cfg.distillation.max_depth and ccp_alpha passed to the sklearn estimator constructor.
\(G\)
Global redistilled surrogate — \(\arg\min\) of the objective. The single tree broadcast back to all clients.
G = self.distiller.distill(proxy_X, P_bar, classes); wrapped as GlobalArtifact by the coordinator.
Variance bound & privacy inheritance
\(P_k\)
Per-client probability surface evaluated on the proxy (a per-row random vector). Variance is taken over the DP noise and the partition randomness.
S_k.predict_proba(proxy_X); equals the post-DP target after the noised distillation step.
\(\mathrm{Var}(\cdot)\)
Component-wise variance of a probability surface; the quantity Jensen's inequality bounds when averaging in label space. The double bound shows uniform weights minimise variance.
Measured empirically in aggregation/_telemetry.py (per-row std across clients); reported in RoundResult.aggregation_metrics["proxy_var"].
\(\varepsilon_k, \delta_k\)
Per-client privacy budget already paid to produce \(\tilde P_k\) (and therefore \(S_k\)). \(\bar P\) inherits \(\min_k(\varepsilon_k,\delta_k)\) by post-processing.
PrivacyAccountant.cumulative() rows; aggregator never spends new budget — it only reads ClientUpdate.epsilon.
Note. Aggregation in FedRF-Distill is a simplex operation: every step (\(\bar P\), redistil into \(G\)) is a deterministic function of public proxy points \(x_i\) and already-privatised \(S_k\) outputs, so the broadcast \(G\) inherits the strictest client budget without any additional noise.
