One Federation Round, Stage by Stage

From raw local data to a refined, cross-client-aware model — in 7 steps
DIAGRAM 02 / 16
STEP 1

Local teacher fit

client
Train the teacher (RF / XGBoost / LightGBM / CatBoost) on the client's private partition.
→ teacher
STEP 2

Soft labels

client
teacher.predict_proba(X_local) with optional temperature T and floor.
→ P ∈ ℝn×k
STEP 3

DP noise (Hook A)

client
Add Laplace / Gaussian noise calibrated to (ε, δ). Clip to [0, 1] + renormalise → still (ε, δ)-DP by post-processing.
→ P̃ (private)
STEP 4

Distill surrogate

client
Fit a depth-6 decision tree on (X_local, P̃) via argmax+weight or multi-output regression.
→ student (∼10 KB)
STEP 5

Aggregate

coordinator
Each student runs on the shared proxy_X. Average the probability outputs. Re-distill the ensemble.
→ G (global surrogate)
STEP 6

Broadcast

coordinator
Pack G into a GlobalArtifact: blob + class path + classes + strategy name + cumulative ε.
→ artifact_t
STEP 7

Meta-refine

client
Stacking: X_aug = [X_local || G.predict_proba(X_local)] then retrain local model on (X_aug, y_local).
→ refined local model
