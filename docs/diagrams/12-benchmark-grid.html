Mathematical Foundation
Cartesian product is a factorial experimental design
▌ WHAT — sample size math
A 4-factor full-factorial $\times$ seeds $\times$ rounds = the entire study. Variance decomposition lets us attribute drift to each factor:
$|\mathcal{D}| \cdot |\mathcal{P}| \cdot |\mathcal{M}| \cdot |\mathcal{F}| \cdot |S| \cdot |T| \;=\; 10 \cdot 4 \cdot 4 \cdot 3 \cdot 3 \cdot 5 \;=\; 7{,}200\ \text{round-evaluations}$
$\overline{\mathrm{acc}} = \dfrac{1}{S}\sum_{s=1}^{S}\mathrm{acc}(\mathrm{seed}=s),\quad \mathrm{std} = \sqrt{\dfrac{\mathrm{Var}_s(\mathrm{acc})}{S}}$
$\mathrm{SS}_{\mathrm{total}} = \mathrm{SS}_{\mathcal{D}} + \mathrm{SS}_{\mathcal{P}} + \mathrm{SS}_{\mathcal{M}} + \mathrm{SS}_{\mathcal{F}} + \mathrm{SS}_{\mathrm{inter}} + \mathrm{SS}_{\mathrm{resid}}$
# $F$-test per factor; $\alpha = 0.05$. Wall-clock budget: ~6h on M3 Max
▌ WHY — full factorial > ad-hoc tuning
Without a sweep you can't decompose error. Is FedRF-Distill bad on a dataset because of the data, the partition, or the DP? Full-factorial design separates these.

10 datasets give external validity. An average over diverse domains (medical, finance, physics, cyber) bounds generalisation. The paper claim "robust to non-IID" is only credible at this scale.

3 seeds per cell are the bare minimum to compute a standard deviation. The benchmark is reproducible: same seed → same number.
▌ MINDSET — one CSV is the artefact
All science is the CSV. Plots, tables, headline numbers — every figure in the paper is a SQL query against results/benchmark_sweep.csv. No hidden state.

Cells are independent. Each row is a self-contained reproducer (dataset, partition, DP, framework, seed, round). Bench harness rebuilds the world from scratch.

Failure of one cell does not contaminate the rest. Errors get logged with a stack trace; the sweep continues.

What it represents
Where it lives / how it's computed
Factor sets (rows × columns of the sweep)
\(\mathcal{D}\)
Set of datasets — 10 in the sweep: adult, bank_marketing, breast_cancer, covertype, credit_card_fraud, diabetes, higgs, letter_recognition, mushroom, nsl_kdd.
experiments/scripts/run_benchmark_sweep.py --datasets all; loaded by data/datasets.py.
\(\mathcal{P}\)
Set of partition strategies (4): iid, dirichlet α=0.5, dirichlet α=0.1, pathological k=2.
data/partitioners.py; selected via --partitions flag.
\(\mathcal{M}\)
Set of DP mechanisms (4): null (ε=∞), laplace ε=5, gaussian ε=1, gaussian ε=0.5.
privacy/mechanisms.py; selected via --dp flag.
\(\mathcal{F}\)
Set of framework mixes (3): all-sklearn, mixed-4, all-xgb — which teacher backends each client uses.
core/adapters/; selected via --frameworks flag.
\(S\)
Set of random seeds — 3 per cell, enough to compute a std-dev.
--seeds 3 CLI arg; seeds the global numpy.random.Generator for partitioning, DP noise, model init.
\(T\)
Number of federation rounds reported per run — 5 in the headline sweep.
--rounds 5 CLI arg; consumed by FederatedCoordinator.
Cardinality & total cost
\(|\mathcal{D}|\cdot|\mathcal{P}|\cdot|\mathcal{M}|\cdot|\mathcal{F}|\)
Treatment-cell count: \(10\cdot4\cdot4\cdot3=480\) — one CSV row per cell.
Materialised as 480 rows in results/benchmark_sweep.csv; one cell per (dataset, partition, DP, framework_mix).
\(|\mathcal{D}|\cdot|\mathcal{P}|\cdot|\mathcal{M}|\cdot|\mathcal{F}|\cdot|S|\cdot|T|\)
Total round-evaluations: \(10\cdot4\cdot4\cdot3\cdot3\cdot5=7{,}200\) federated rounds executed.
Logged as n_round_evals in the sweep manifest header.
Per-cell point estimate
\(\mathrm{acc}(\mathrm{seed}=s)\)
Test-set accuracy of the global model \(G\) at the final round for seed \(s\).
evaluation/metrics.py:test_accuracy(G, X_test, y_test); written to row.acc_seed_s.
\(\overline{\mathrm{acc}}\)
Per-cell sample mean of accuracy across the \(S\) seeds.
row.acc_mean = np.mean([acc_seed_s for s in seeds]).
\(\mathrm{std}\)
Standard error of the per-cell mean: \(\sqrt{\mathrm{Var}_s(\mathrm{acc})/S}\).
row.acc_std = np.std(per_seed_accs, ddof=1) / sqrt(S).
\(\mathrm{Var}_s(\mathrm{acc})\)
Within-cell variance of accuracy across seeds — the residual / noise variance.
np.var(per_seed_accs, ddof=1).
ANOVA decomposition
\(\mathrm{SS}_{\mathrm{total}}\)
Total sum-of-squares of accuracy around the grand mean across all cells.
analysis/anova.py:decompose(); reported in the paper's variance table.
\(\mathrm{SS}_{\mathcal{D}}\)
Sum-of-squares attributable to the dataset factor — how much accuracy variance is "because of which dataset".
Marginal-means computation in analysis/anova.py; uses statsmodels.api.stats.anova_lm.
\(\mathrm{SS}_{\mathcal{P}}\)
Sum-of-squares attributable to the partition factor — measures non-IID robustness cost.
Same routine; reported as % of \(\mathrm{SS}_{\mathrm{total}}\) in the paper.
\(\mathrm{SS}_{\mathcal{M}}\)
Sum-of-squares attributable to the DP mechanism factor — directly quantifies "privacy tax".
Same routine.
\(\mathrm{SS}_{\mathcal{F}}\)
Sum-of-squares attributable to the framework-mix factor — tests heterogeneity sensitivity.
Same routine.
\(\mathrm{SS}_{\mathrm{inter}}\)
Interaction sums-of-squares (e.g. partition × DP) — non-additive effects.
Two- and three-way interaction terms from anova_lm(typ=2).
\(\mathrm{SS}_{\mathrm{resid}}\)
Residual / seed-level sum-of-squares — irreducible noise after all factors accounted for.
Output of the ANOVA fit; equals \(\sum_{\text{cells}}\mathrm{Var}_s(\mathrm{acc})\,(S-1)\).
Inference
\(F\)-test
Per-factor F-statistic — ratio of factor MS to residual MS; reports whether the factor moves accuracy significantly.
analysis/anova.py reports F and p-value per factor.
\(\alpha = 0.05\)
Significance threshold for the F-tests.
Hardcoded in analysis/anova.py; Bonferroni-corrected when multiple factors are tested.
Note. The cartesian product \(|\mathcal{D}|\cdot|\mathcal{P}|\cdot|\mathcal{M}|\cdot|\mathcal{F}|\cdot|S|\cdot|T|=7{,}200\) round-evaluations are not "lots of runs" — they are a factorial design. The ANOVA decomposition \(\mathrm{SS}_{\mathrm{total}}=\mathrm{SS}_{\mathcal{D}}+\mathrm{SS}_{\mathcal{P}}+\mathrm{SS}_{\mathcal{M}}+\mathrm{SS}_{\mathcal{F}}+\mathrm{SS}_{\mathrm{inter}}+\mathrm{SS}_{\mathrm{resid}}\) is what turns a benchmark grid into a causal claim.
