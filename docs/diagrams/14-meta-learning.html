Architecture — what StackedAdapter looks like under the hood

WHY STACKING (NOT FedAvg)?

Trees don't average in parameter space — there is no weight tensor to mean. Stacking sidesteps the issue: the global model becomes a feature, not a parameter set.

WHY MetaLearnerProtocol?

Stacking is the canonical strategy, but distillation-on-augmented-data and gating networks fit the same protocol. Future work plugs in here.

HOW THE LOCAL MODEL USES G

The first-split decisions in the refined tree often select G_proba columns as the most informative feature when local data is class-skewed — letting raw features dominate only where G is unsure.

# Stacking is one of the protocols — swap by string in the config class StackingMetaLearner: name = "stacking" def refine(self, X_local, y_local, global_surrogate, local_model_factory): proba_aug = global_surrogate.predict_proba(X_local) # (n, k) X_aug = np.hstack([X_local, proba_aug]) # (n, d+k) refined = local_model_factory() # fresh adapter refined.fit(X_aug, y_local) return StackedAdapter(inner=refined, global_surrogate=global_surrogate)

Mathematical Foundation
Stacked generalisation — the Wolpert 1992 idea
▌ WHAT — formal stacking
The refined model is the composition of an augmenter (concatenate $G$'s prediction) and a base learner that's free to ignore it:
$\varphi_G:\mathbb{R}^{d} \to \mathbb{R}^{d+K},\quad \varphi_G(x) = x \oplus G.\mathrm{predict\_proba}(x)$
$M_k(x) \;=\; M_k^{\mathrm{raw}}\bigl(\varphi_G(x)\bigr),\quad M_k^{\mathrm{raw}} = \mathrm{RF}.\mathrm{fit}\bigl(\{(\varphi_G(x_i),\,y_i)\}\bigr)$
$\mathrm{err}(M_k) \;\le\; \min\bigl(\mathrm{err}(S_k),\,\mathrm{err}(G)\bigr) + \varepsilon_{\mathrm{stack}},\quad \varepsilon_{\mathrm{stack}} \xrightarrow{n_{\mathrm{local}}\to\infty} 0$
# $G_{\mathrm{proba}}$ columns are scale-free ⇒ no standardisation required for trees
▌ WHY — stacking is the only choice for trees
Trees have no weight tensor to average. FedAvg is undefined. FedProx, FedNova, SCAFFOLD — all rely on a gradient or a parameter difference. None apply.

Stacking sidesteps this entirely. The global G becomes a feature, the local model decides how much to trust it. Trees discover the trust weight by selecting the G-proba columns at the most informative splits.

If G is bad on this client, the refined tree ignores the augmented columns and falls back to the raw features — no harm done.
▌ MINDSET — model the trust, not the parameters
Federated learning is fundamentally an opinion-merging problem. The global model has one opinion (from all clients), the local model has another (from its private data). Stacking is the math for "trust this much of each".

StackedAdapter auto-augments at predict-time. Caller never has to remember the trick. The drop-in nature means any downstream evaluator works unchanged.

The local model and the global model see different worlds. Combining them lets the federation benefit from both — without one overriding the other.

\(\mathrm{err}(\cdot)\)
Generalisation (population) error of a classifier on client \(k\)'s data distribution; the quantity Wolpert/Breiman bound.
Estimated by held-out test accuracy in eval(M_k, X_test, y_test); reported as round_result.meta_acc.
\(S_k\)
Client \(k\)'s local surrogate from the distillation phase — the "trust only the local data" baseline the stack must not regress past.
self.surrogate after local_train; cached on the client for the err-bound diagnostic.
\(\varepsilon_{\mathrm{stack}}\)
Excess risk introduced by stacking with a finite training set; vanishes as \(n_{\mathrm{local}}\to\infty\) when the meta-learner is consistent.
Not computed directly; bounded operationally by ensuring n_local \ge 50 in cfg.meta.min_samples.
\(n_{\mathrm{local}}\)
Row count on client \(k\) — the sample size driving the stacking consistency rate.
X_local.shape[0]; surfaced as ClientUpdate.n_samples.
Note. Stacking is the only federation-compatible refinement for tree-based learners — there is no weight tensor to FedAvg. By making \(G\) a feature rather than a parameter, \(M_k\) can ignore the global when it disagrees, giving the \(\min(\mathrm{err}(S_k),\mathrm{err}(G))\) bound for free.
