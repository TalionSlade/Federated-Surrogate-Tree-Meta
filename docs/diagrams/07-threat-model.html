Mathematical Foundation
(ε, δ)-DP — what the adversary is bounded to
▌ WHAT — Dwork's definition
A randomised mechanism $\mathcal{M}:\mathcal{D}\to\mathcal{Y}$ is $(\varepsilon,\delta)$-differentially private if for any pair of neighbouring datasets $D,D'$ (differing by one row) and any measurable $S\subseteq\mathcal{Y}$:
$\Pr[\mathcal{M}(D) \in S] \;\le\; e^{\varepsilon}\cdot \Pr[\mathcal{M}(D') \in S] \;+\; \delta$
$\forall\,\mathcal{A},\ \forall\,\pi:\quad \bigl|\Pr_{\mathcal{A}}[\text{in } D \mid \mathcal{M}(D)] - \pi\bigr| \;\le\; \mathrm{bound}(\varepsilon,\delta)$
$\forall\, f:\mathcal{Y}\to\mathcal{Z}:\quad f\circ\mathcal{M}\ \text{is}\ (\varepsilon,\delta)\text{-DP}$
# Post-processing ⇒ surrogate, G, M_k all inherit DP
▌ WHY — three adversaries, one guarantee
Honest client — trusted; the threat model assumes its process boundary is secure (OS-level).

Honest-but-curious coordinator — runs the protocol but logs everything. DP bounds what it can learn from the soft labels.

External eavesdropper — out of scope at the DP layer; addressed at deployment by TLS.

The Dwork bound applies to the strongest threat in scope: the curious coordinator. Every other adversary is weaker, so it inherits the same protection.
▌ MINDSET — trust nothing, prove everything
We don't say "the data is safe." We say: for any adversary, the probability they can identify one row's contribution is bounded by eε. ε is the only knob.

Pick ε before pick utility — the framework refuses to continue rounds that exceed the target budget. Privacy is the contract; accuracy is what falls out of it.

Empirically validate analytically — the MIA in privacy.attack runs after training to measure the leak. Both numbers must agree.

Every symbol in Dwork's definition and the post-processing closure — what it is, where it lives, how it's computed

Symbol
What it represents
Where it lives / how it's computed
The mechanism & its data domain
\(\mathcal{M}\)
Randomised mechanism — the only stochastic step in the pipeline. Maps datasets to outputs.
privacy/mechanisms.py:BaseDPMechanism.privatize(P, ε, δ) — instances: LaplaceMechanism, GaussianMechanism, NullDPMechanism.
\(\mathcal{D}\)
Input data domain — the space of all valid client datasets (feature matrix + soft labels).
Conceptually (X_local, P); concretely the soft-label row space inside FederatedClient.local_train().
\(\mathcal{Y}\)
Output space of \(\mathcal{M}\) — the simplex of privatised soft-label rows \(\tilde{P}\).
Return type of privatize(): shape \((n_k,\, |\mathcal{C}|)\) row-stochastic array.
\(D, D'\)
Neighbouring datasets — differing by the addition / removal of a single row (the "one-row-out" semantics).
Implicit in the sensitivity bound proven in privacy/mechanisms.py docstrings; tested via leave-one-out in tests/test_privacy_sensitivity.py.
\(S\)
Any measurable subset of \(\mathcal{Y}\) — the "event" the adversary tries to discriminate on.
Not materialised in code; appears only in the DP proof obligation.
Privacy parameters
\(\varepsilon\)
Per-round privacy loss budget — bounds \(\log\)-ratio of output probabilities between neighbouring datasets.
cfg.dp.target_epsilon / n_rounds in configs/*.yaml; passed into privatize(P, ε, δ).
\(\delta\)
Failure probability — the mass under which the \(e^{\varepsilon}\) bound is allowed to break.
cfg.dp.target_delta; typically \(10^{-5}\). Required > 0 for Gaussian, must be 0 for Laplace.
\(e^{\varepsilon}\)
Multiplicative likelihood-ratio bound — the factor by which adversary's posterior on membership can shift.
Plugged into MIA hypothesis test as a worst-case TPR/FPR bound (verified empirically in evaluation/mia.py).
Adversaries & post-processing
\(\mathcal{A}\)
An arbitrary adversary — any computable function of the mechanism's output (in scope: the honest-but-curious coordinator).
Operationalised by evaluation/mia.py:MembershipInferenceAttack.
\(\pi\)
Adversary's prior over the membership hypothesis — appears in the Bayesian-shift bound.
Implicit; not stored. Posterior shift is bounded by \(\mathrm{bound}(\varepsilon,\delta)\) at the threshold step.
\(\mathrm{bound}(\varepsilon,\delta)\)
The Kairouz-Oh-Viswanath posterior-shift bound — closed form in \((\varepsilon,\delta)\).
Reference bound in MIA reporting; not computed in code, used only as a sanity ceiling on empirical TPR.
\(f:\mathcal{Y}\to\mathcal{Z}\)
Any data-independent post-processing function — the post-processing theorem says \(f\circ\mathcal{M}\) inherits DP.
Realised by every downstream call: SurrogateDistiller.distill, Aggregator.aggregate, MetaLearner.refine.
\(f\circ\mathcal{M}\)
Composition of \(\mathcal{M}\) with a post-processor — still \((\varepsilon,\delta)\)-DP. The free guarantee.
Surrogate \(S_k\), global \(G\), refined \(M_k\) — all functions of \(\tilde{P}_k\) + public proxy data, so all DP.
Downstream DP-inheriting artefacts
\(\text{surrogate}\)
The per-client distilled tree \(S_k\) — function of \(\tilde{P}_k\) only, hence \((\varepsilon,\delta)\)-DP.
distillation/surrogate.py:SurrogateDistiller.distill(X, P̃).
\(G\)
Global redistilled model — function of \(\{S_k\}\) + proxy_X (public).
aggregation/proxy_redistillation.py:ProxyRedistillation.aggregate().
\(M_k\)
Client \(k\)'s meta-refined model — function of \(G\) + local data, DP-inherited through \(G\).
meta/stacking.py:StackedAdapter wrapping a fresh local re-fit.
Invariant. Once \(\mathcal{M}\) injects calibrated noise once at privatize(), the post-processing theorem \(\forall f:\ f\circ\mathcal{M}\) is \((\varepsilon,\delta)\)-DP guarantees that surrogate, global \(G\), and meta \(M_k\) all inherit the same DP bound — no further noise needed.
