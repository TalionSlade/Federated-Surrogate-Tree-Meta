Protected assets — what FedRF-Distill defends

RAW_DATA
Xlocal, ylocal per client. Never leaves the client process.
PROTECTED — never transmitted
SOFT_LABELS (P)
Teacher's predict_proba on Xlocal. Used only locally for distillation.
PROTECTED — never transmitted
SURROGATE
Compact tree (~10 KB) fit on (Xlocal, P̃). Trained on DP-noised labels.
PARTIAL — covered by (ε, δ)-DP
METADATA
n_samples, framework, classes — exposed for audit. Not protected by design.
EXPOSED — by-design

Attack surface matrix

Attack What the adversary does FedRF-Distill defence Residual risk
Membership Inference (MIA) privacy.attack Given a row (x, y), decide if it was in Xlocal by inspecting surrogate.predict_proba(x). DP on soft labels ⇒ post-processing immunity. Tunable via ε. Higher ε ⇒ higher TPR@1%FPR. Reported in MIAResult.
Property Inference Infer aggregate properties (e.g. class skew) of Xlocal from the surrogate. Soft labels carry the property; DP noise masks at fine granularity. Coarse global statistics (e.g. dominant class) may still leak.
Model Inversion Reconstruct prototype rows from surrogate decision paths. Depth-bounded student + DP-noised labels limit gradient signal. Out-of-scope for shallow trees; quantitatively bounded by ε.
Replay / Tampering Modify a ClientUpdate in flight to bias the global model. safe_deserialize refuses unknown class paths. Signed transport at deployment. Malicious-client poisoning is out-of-scope (orthogonal robust-agg defences).
