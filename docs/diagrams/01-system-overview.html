Layered architecture: every package, what it owns, what it does

Core

fedrf_distill.core

The contract layer. Every other package talks to protocols defined here — never to concrete classes — so plug-replacement happens for free.

  • Protocols — ModelAdapter, Distiller, DP, Aggregator, Meta, Partitioner, Client, Coordinator
  • Types — ClientID, FeatureMatrix, SoftLabels, ClientUpdate, GlobalArtifact, PrivacyBudget
  • Exceptions — single root FedRFDistillError with typed leaves
∮

Models

fedrf_distill.models

Uniform adapter API over four major tree frameworks — the foundation for Hook B (cross-framework heterogeneity).

  • BaseModelAdapter — refit guard, binary→2D reshape, safe pickling
  • Adapters — sklearn RF/DT, XGBoost, LightGBM, CatBoost
  • Factory — string-keyed registry + auto-discovery of optional backends
⏃

Distillation

fedrf_distill.distillation

Turn a heavy teacher into a 10 KB student by mimicking its soft labels.

  • SoftLabelGenerator — temperature scaling, label floor
  • SurrogateDistiller — two strategies: argmax+weight, multi-output regression
  • Wire-format: pickled adapter + qualified class path
⛨

Privacy HOOK A

fedrf_distill.privacy

Formal (ε, δ)-DP on every soft-label release. Carries an audit ledger and runs empirical attacks for the paper.

  • Mechanisms — Laplace (pure ε), Gaussian (ε,δ), Null (control)
  • Accountants — Basic composition, Rényi DP
  • Threat model — adversary × asset × guarantee
  • Attack — Yeom-style MIA with TPR-at-low-FPR
∑

Aggregation

fedrf_distill.aggregation

Merge K client surrogates into one global surrogate.

  • Proxy re-distillation (default, novel) — average on proxy, then distil again
  • Confidence-weighted — FedAvg-style sample weighting
  • Majority vote — discrete-label baseline
↻

Meta-learning

fedrf_distill.meta

Each client refines its local model using the broadcast global surrogate.

  • StackingMetaLearner — augment X_local with G.predict_proba
  • StackedAdapter — auto-augments at predict-time (drop-in)
◐

Client

fedrf_distill.client

Holds local data + teacher + DP. One method per protocol step:

  • local_train() → ClientUpdate
  • apply_global(artifact) — refines via meta-learner
  • evaluate_local(X, y) → metrics dict
⌖

Coordinator

fedrf_distill.coordinator

Owns the proxy + aggregator + accountant. Refuses to continue when the total privacy budget would be exceeded.

  • round(updates, t, budget) → GlobalArtifact
  • Maintains privacy ledger across rounds
  • Raises PrivacyBudgetExhausted on overshoot
▶

Orchestration

fedrf_distill.orchestration

The composition root. YAML → typed config → wired components → round loop.

  • ExperimentRunner — end-to-end driver returning RoundResult[]
  • Wires every protocol implementation from ExperimentConfig
📦 Configpydantic v2
ExperimentConfig + 8 sub-schemas. Frozen, validated, YAML-friendly.
🗂 Data10 loaders
UCI, OpenML, Kaggle. Cached to ~/.cache/fedrf_distill/ as .npz.
📐 Metricsnumpy-only
Accuracy, F1-macro, OvR AUC, KL fidelity — no sklearn import.
🔧 Utilsserialisation, seeds, timers
Safe deserialiser refuses non-adapter classes. Deterministic seeding.
