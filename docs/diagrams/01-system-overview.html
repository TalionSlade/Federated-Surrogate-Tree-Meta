Mathematical Foundation
The system is a function composition
▌ WHAT — mathematics
The entire stack is one composable map. Each package owns one arrow. Per client \(k\), per round \(t\):
$$\begin{aligned} X_k & \xrightarrow{\text{teacher.fit}} \mathcal{T}_k \\ \mathcal{T}_k & \xrightarrow{\text{predict\_proba}} P_k \in \mathbb{R}^{n\times K} \\ P_k & \xrightarrow{\text{soft}_T,\text{floor}} P_k^{(T)} \\ P_k^{(T)} & \xrightarrow{\mathrm{DP}(\varepsilon,\delta)} \tilde{P}_k \\ (X_k, \tilde{P}_k) & \xrightarrow{\text{distil}} S_k \\ \{S_k\}_{k=1}^{K} & \xrightarrow{\text{aggregate}} G \\ (X_k, G) & \xrightarrow{\text{stacking}} M_k \end{aligned}$$
$$\Phi : \mathcal{D} \times \Theta \to \mathcal{G}, \qquad M_k = \mathrm{stack}(S_k, G)$$
▌ WHY — motivation
Tree ensembles have no weight tensor to mean — FedAvg is impossible. We need a representation that does compose: the probability simplex.

Every package above exists to move data into that simplex (distillation), protect it there (DP), combine it there (aggregation), and project it back (stacking). The package boundary is the type boundary.

Protocols, not classes: structural typing means any new tree backend, any new DP scheme, any new aggregator drops in without touching the runner.
▌ MINDSET — design philosophy
I1 · Soft labels are the lingua franca. Raw rows never cross the wire.

I2 · DP is post-processing-stable. Add noise once, inherit the guarantee forever.

I3 · Compositionality > centralisation. Each layer is a pure function of typed inputs — easy to test, easy to swap.

I4 · Heterogeneity is a feature. Clients pick their own teacher (Hook B); the wire format is framework-agnostic by virtue of the adapter protocol.

I5 · The accountant has veto power. Privacy budget is the only kill-switch the coordinator obeys.

Indices & population
\(k\)
Client index, \(k \in \{1,\dots,K\}\). One participant in the federation.
FederatedClient.client_id; enumerated by Coordinator.clients.
\(K\)
Total number of clients in the round. Drives the outer product \(\{S_k\}_{k=1}^{K}\).

\(t\)
Round index, \(t \in \{1,\dots,R\}\). Each round runs the full Φ pipeline once.
Coordinator.run(n_rounds) loop counter; stamped on RoundLedger.round_id.
Local data & teacher (X → 𝒯)
\(X_k\)
Private feature matrix on client \(k\); shape \((n, d)\). Never leaves the client.
FederatedClient.X_local — set from a Partitioner shard in partitioners.py.
\(n, d\)
Row count and feature dimensionality of \(X_k\) (\(d\) is global, \(n\) is per-client).
X_k.shape; \(n\) is the n_samples field on ClientUpdate.
\(\mathcal{T}_k\)
Local teacher model fit on \((X_k, y_k)\) — a tree ensemble (RF, XGBoost, LightGBM, …).
self.teacher = self.teacher_factory(); self.teacher.fit(...) in client/client.py::local_train.
Soft labels & temperature (𝒯 → P → P^(T))
\(P_k \in \mathbb{R}^{n \times K}\)
Raw teacher posteriors over \(K\) classes on the client's own rows. Row-stochastic.
self.teacher.predict_proba(self.X_local) inside distillation/soft_labels.py.
\(T\)
Distillation temperature. \(T=1\) reproduces the teacher's posterior; \(T \to \infty\) yields the uniform distribution (max entropy).
cfg.distillation.temperature; applied by SoftLabelGenerator.apply_temperature.
\(P_k^{(T)}\)
Temperature-softened soft labels with optional probability floor — same shape as \(P_k\), softer entropy.
Output of soft\_T(\cdot); computed as softmax(log P / T) then floored / renormalised.
Differential privacy (P^(T) → P̃)
\(\mathrm{DP}(\varepsilon, \delta)\)
The DP mechanism — Laplace, Gaussian, or null — that injects calibrated noise into \(P_k^{(T)}\).
privacy/mechanisms.py; selected by _build_dp_mechanism(cfg).
\(\varepsilon, \delta\)
Per-round privacy budget. \(\varepsilon\) bounds the log-divergence of neighbouring outputs; \(\delta\) the failure mass.
cfg.dp.target_epsilon / n_rounds, cfg.dp.target_delta; tracked by PrivacyAccountant.
\(\tilde{P}_k\)
Privatised soft labels — the only random object in the pipeline. Same shape as \(P_k\), still row-stochastic after clip/renormalise.
dp_mechanism.privatize(P_T, eps, delta) — returned with provenance to FederatedClient.local_train.
Distillation, aggregation, stacking (S, G, M)
\(S_k\)
Per-client surrogate tree (~10 KB) fit on \((X_k, \tilde{P}_k)\). The only object that goes on the wire.
S_k = self.distiller.distill(X_local, P_tilde, classes) in distillation/surrogate.py.
\(\{S_k\}_{k=1}^{K}\)
The collection of all surrogate trees received by the coordinator this round.
updates: list[ClientUpdate] arriving at Coordinator.run_round.
\(G\)
Global surrogate distilled from the averaged predictions of \(\{S_k\}\) on the public proxy set.
aggregation/proxy_redistillation.py::ProxyRedistillationAggregator.aggregate.
\(M_k\)
Client \(k\)'s refined local model. A stacked ensemble that uses \(G\)'s predictions as extra features alongside \(S_k\).
meta/stacking.py::StackingMetaLearner.refine(X_k, y_k, G, teacher_factory).
The composition operator
\(\Phi\)
The end-to-end pipeline as a typed function: data & config → global artifact. \(\Phi = \mathrm{stack} \circ \mathrm{aggregate} \circ \mathrm{distil} \circ \mathrm{DP} \circ \mathrm{soft}_T \circ \mathrm{teacher}\).
Realised by Coordinator.run; each arrow is one package boundary.
\(\mathcal{D}\)
The space of per-client datasets \((X_k, y_k)\) — the input type of \(\Phi\).
Produced by partitioners.py (IID / Dirichlet / label-skew).
\(\Theta\)
The configuration / hyperparameter space (teacher choice, \(T\), \(\varepsilon\), depth, …).
config/schemas.py::FederationConfig; injected once at construction.
\(\mathcal{G}\)
The space of global artifacts — wrapped surrogates implementing the adapter protocol.
GlobalArtifact dataclass; consumed by clients for stacking.
Invariant. \(\Phi\) is a pure composition of typed arrows, so swapping any single arrow (teacher backend, DP mechanism, aggregator, meta-learner) preserves the rest of the pipeline. The DP arrow is the only randomised one — every later object inherits \((\varepsilon, \delta)\)-DP by post-processing.
