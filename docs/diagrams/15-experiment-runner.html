Mathematical Foundation
Config → wiring → round loop is a single function
▌ WHAT — runner type signature
The runner is one map from a frozen typed config to a list of $\mathrm{RoundResult}$. Every intermediate is derived deterministically:
$\mathrm{ExperimentRunner.run}\;:\;\mathrm{ExperimentConfig}\;\longrightarrow\;\mathrm{List}[\mathrm{RoundResult}]$
$\begin{aligned} \mathrm{seed} &\leftarrow \mathrm{set\_global\_seed}(\mathrm{cfg.random\_state}) \\ \mathcal{D} &\leftarrow \mathrm{load\_dataset}(\mathrm{cfg.data.name}) \\ \{X_k,y_k\}_{k=1}^{K} &\leftarrow \mathrm{partitioner.partition}(X,y,K) \\ \{c_k\}_{k=1}^{K} &\leftarrow \mathrm{build\_clients}(\mathrm{cfg},\,\{X_k,y_k\}) \\ \Gamma &\leftarrow \mathrm{build\_coordinator}(\mathrm{cfg},\,\mathcal{C},\,d) \end{aligned}$
$\begin{aligned} \forall\, t \in \{1,\dots,T\}:\quad U_t &\leftarrow \{c_k.\mathrm{local\_train}()\}_{k=1}^{K} \\ \mathcal{A}_t &\leftarrow \Gamma.\mathrm{round}(U_t,\,t,\,B) \\ &\quad \forall\, c_k:\ c_k.\mathrm{apply\_global}(\mathcal{A}_t) \\ m_t &\leftarrow \mathrm{eval}(G_t,\,X_{\mathrm{test}},\,y_{\mathrm{test}}) \end{aligned}$
# Deterministic: same config ⇒ same results
▌ WHY — composition root pattern
One place in the codebase knows about every concrete class. Everywhere else, code talks to protocols. This is the composition-root pattern from Mark Seemann.

Pure builders (_build_*) are total functions from string keys to objects. They're easy to test in isolation, easy to mock, and have no side effects.

Hook B (mixed frameworks) lives here. If frameworks_per_client is set, the runner instantiates a different teacher per client — without touching the round loop.
▌ MINDSET — YAML drives everything
An ExperimentConfig is the entire experiment. No CLI flags, no environment variables, no hidden state. YAML in, results out.

Pydantic v2 validation rejects malformed configs before the runner starts. Type errors at parse-time, not at round 5.

The runner is stateless across runs. Two ExperimentRunner instances with the same config produce bit-identical RoundResult lists — that's how the benchmark sweep reproduces.

Top-level type signature
\(\mathrm{ExperimentConfig}\)
Frozen pydantic v2 model describing the entire run — data, partitioner, dp, distillation, aggregation, meta, federation, seeds.
orchestration.config.ExperimentConfig; loaded from YAML by ExperimentRunner.from_yaml.
\(\mathrm{ExperimentRunner.run}\)
The single entry-point: a pure function from config to a list of round results. Deterministic given seed.
orchestration/runner.py::ExperimentRunner.run(self) -> list[RoundResult].
\(\mathrm{RoundResult}\)
Per-round dataclass: round id, global accuracy, per-client metrics, ε/δ ledger row, wall-clock.
orchestration.result.RoundResult; appended once per round inside the loop.
Bootstrap algebra (one-shot)
\(\mathrm{cfg.random\_state}\)
Master seed propagated to NumPy, Python, and every estimator. Sole randomness source.
set_global_seed(cfg.random_state) at the top of run().
\(\mathcal{D}\)
Raw dataset \((X, y)\) before partitioning — the pre-federation reference table.
load_dataset(cfg.data.name) in data/loaders.py.
\(\{X_k, y_k\}_{k=1}^{K}\)
Per-client shards produced by the chosen partitioner (IID, label-skew Dirichlet, quantity-skew, feature-skew).
partitioner.partition(X, y, K) in data/partitioners.py.
\(K\)
Number of federated clients; cardinality of the shard collection.
cfg.federation.n_clients.
\(c_k\)
A constructed FederatedClient bound to shard \((X_k, y_k)\), a teacher factory, a DP mechanism, and a distiller.
build_clients(cfg, shards); returns list[FederatedClient].
\(\mathcal{C}\)
Global class list — the canonical class ordering shared by every estimator and aggregator.
np.unique(y); passed to build_coordinator for class-aligned proba columns.
\(d\)
Feature dimensionality threaded into the coordinator builder (needed for proxy synthesis).
X.shape[1].
\(\Gamma\)
The coordinator — wires together aggregator, accountant, proxy dataset, and meta-learner factory.
build_coordinator(cfg, classes, d) in orchestration/runner.py.
Round-loop algebra
\(t\)
Round index, ranging \(1\dots T\). Used as the accountant's row key.
Loop variable in for t in range(1, cfg.federation.n_rounds + 1):.
\(T\)
Total number of federated rounds. Determines per-round budget split \(\varepsilon/T\).
cfg.federation.n_rounds.
\(U_t\)
Collection of ClientUpdates for round \(t\) — one per client, each containing its surrogate blob, \(n_k\), and per-client ε.
updates = [c.local_train() for c in clients].
\(B\)
Per-round privacy budget \(\varepsilon/T\) passed to the coordinator so it can verify the accountant.
cfg.dp.target_epsilon / cfg.federation.n_rounds.
\(\mathcal{A}_t\)
Aggregated broadcast artefact for round \(t\) — wraps the global \(G_t\), accountant snapshot, and metadata.
coordinator.round(updates, t, B) returns a GlobalArtifact.
\(G_t\)
Global surrogate at round \(t\); the model evaluated on the held-out test set for the round's accuracy row.
artifact.model from GlobalArtifact.
\(m_t\)
Per-round metric tuple (accuracy, F1, AUC, ε_cum). The summary value stored in RoundResult.
eval(G_t, X_test, y_test); written to RoundResult.metrics.
\(X_{\mathrm{test}}, y_{\mathrm{test}}\)
Federation-wide held-out split — never seen by any client, used only for centralised evaluation of \(G_t\).
cfg.data.test_split; carved out before partitioning in load_dataset.
Note. The runner is a composition root: the one place that knows every concrete class. The bootstrap algebra runs once, the round-loop algebra runs \(T\) times, and the entire function is deterministic — same ExperimentConfig, bit-identical List[RoundResult].
