Student objective — what Sk is trying to approximate

Idealised distillation loss

The student Sk is the minimiser of an empirical KL-divergence between its own predictive distribution and the (privatised) teacher's:

Sk★ = argminS∈𝓢   (1/n) Σᵢ KL(P̃[i] ‖ S.predict_proba(xᵢ))

Here 𝓢 is the hypothesis class of depth-bounded decision trees. Because CART cannot directly minimise KL on probability targets, the implementation reduces this to two tractable surrogate problems shown to the right.

Hypothesis class — why a tree?

A depth-h decision tree partitions ℝd into at most 2h axis-aligned hyper-rectangles. Each leaf stores an empirical class distribution.

S(x) = Σℓ ∈ leaves 𝟙{x ∈ Rℓ} · πℓ

Three properties make trees uniquely suited for federated distillation: (i) weighted samples are first-class in sklearn (sample_weight is accepted by .fit natively); (ii) serialised size is O(2h) integers — bandwidth-friendly; (iii) the leaf distribution πℓ is itself a probability simplex, so the student is a valid ModelAdapter without retrofitting a softmax head.

▌ Mode A · DEFAULT

argmax-and-weight

Convert each soft row into a (hard-label, confidence) pair: the most likely class becomes the target, and the row's peak probability becomes its training weight. CART then runs weighted Gini internally — low-confidence rows tug the splits less than high-confidence rows.

# surrogate.py · _argmax_and_weight() y_hat = np.argmax(P_tilde, axis=1) # (n,) w = np.max(P_tilde, axis=1) # (n,) tree = DecisionTreeClassifier( max_depth=max_depth, min_samples_leaf=2, random_state=seed, ) tree.fit(X, y_hat, sample_weight=w) # predict_proba reads leaf-wise empirical distribution S.predict_proba(x) = πleaf(x) ∈ Δ^(k-1)

Math: minimises Σᵢ wᵢ · 𝟙{S(xᵢ) ≠ ŷᵢ} = weighted 0–1 loss. Variance scales with H(P̃[i]) — uncertain rows contribute less to splits.

▌ Mode B · OPTIONAL

multi-output regression

Treat each soft row as a k-dimensional regression target. CART minimises MSE jointly across all k outputs, learning a leaf-wise mean probability vector. Slightly larger trees, but closer to the true KL objective.

# surrogate.py · _regression_mode() tree = DecisionTreeRegressor( criterion="squared_error", max_depth=max_depth, random_state=seed, ) tree.fit(X, P_tilde) # P_tilde shape: (n, k) # Predictions are leaf-mean vectors; # wrap to enforce simplex projection raw = tree.predict(x) # ∈ ℝ^k S.predict_proba(x) = simplex_project(raw) = clip(raw, 0) / Σ clip(raw, 0)

Math: minimises (1/n) Σᵢ ‖P̃[i] − S(xᵢ)‖² ≈ Bregman divergence in L2 norm. Better correlated with KL when P̃ is near-uniform.

End-to-end algorithm — SurrogateDistiller.distill(X, P̃, classes)

1
Validate

Check P̃ rows are simplices (sum≈1, ≥0). Reject NaN. Confirm classes_ length matches P̃.shape[1].

2
Mode select

Branch on mode ∈ {"argmax", "regress"}. Default is argmax — chosen for size + interpretability.

3
Derive targets

Argmax: y_hat, w ← argmax/max of P̃.
Regress: target ← P̃ (passthrough).

4
Fit CART

Build greedy depth-bounded tree using weighted Gini (argmax) or weighted MSE (regress). O(n·d·h) time.

5
Wrap

Embed in SurrogateAdapter exposing predict_proba + classes_. Conforms to ModelAdapter Protocol.

6
Serialize

pickle.dumps(adapter) → blob ≈ 5–15 KB. ClientUpdate = {blob, class_path, ε, δ, n}.

Why depth ≤ 6 (not unlimited)?

— a bound between bias and privacy
Each additional level doubles the leaf count, which means each leaf is fitted on half as many rows — pushing it toward memorising single training points. That is a privacy disaster (memorisation ⇒ MIA-attackable). Depth 6 ⇒ ≤ 64 leaves, so each leaf averages over ~ n/64 rows — a structural smoothing prior compatible with the DP guarantee.

Why sample_weight is mandatory (mode A)?

— preserving teacher confidence in CART
Without weights, a row with P̃ = [0.51, 0.49] (almost a tie) contributes the same to the Gini criterion as a row with P̃ = [0.99, 0.01] (extremely confident). The peak-probability weight makes the tree defer to the teacher's certainty, exactly the same effect as KL-weighting in soft-label classification.

Why aligned classes_, not local classes_?

— federation interop
Client_k may not have seen all global classes (label-skew partitioner). Without aligning classes_ to the federation's canonical order, the global aggregator's averaging step would silently mis-align columns. Padding zero columns for unseen classes preserves probability-vector semantics without lying about what the local teacher saw.

Mathematical Foundation
A surrogate tree is a structural compression of (X, P̃)
▌ WHAT — formal compression
The surrogate distiller realises a measurable map $\psi$ from the $(n,d+K)$ joint table into the depth-$h$ DT space, with bounded description length:
$\psi\;:\;\mathbb{R}^{n\times d} \times \Delta^{n\times(K-1)} \;\longrightarrow\; \mathcal{T}_h,\quad (X,\tilde{P}) \mapsto S$
$|\mathcal{T}_h| \;\le\; (2d)^{2^{h}-1} \cdot K^{2^{h}}$
$|S|_{\mathrm{bits}} \;=\; O\!\bigl(2^{h}\,(\log d + \log K + \log n)\bigr)$
$S^{\star} \;=\; \arg\min_{S\in\mathcal{T}_h} \sum_{i=1}^{n} w_i \cdot \mathbf{1}\{S(x_i) \neq \hat{y}_i\},\quad \hat{y}_i = \arg\max_j \tilde{P}[i,j],\ w_i = \max_j \tilde{P}[i,j]$
$S^{\star} \;=\; \arg\min_{S\in\mathcal{T}_h} \sum_{i=1}^{n} \bigl\lVert \tilde{P}[i] - S.\mathrm{proba}(x_i) \bigr\rVert^{2}$
# Mode A: weighted 0-1. Mode B: multi-output L2. ≈ 5–15 KB for $h=6, d\le 30, K\le 10$
▌ WHY — the tree is the privacy artefact
The student is not just a compressed teacher — it is the only thing that leaves the device. So three privacy-relevant facts must hold about it:

1. Post-processing closure. By the Dwork post-processing theorem, any deterministic function of P̃ inherits its (ε, δ)-DP guarantee. ψ(X, ·) is such a function, so S inherits the privacy of P̃ for free.

2. Bounded leakage. A depth-h tree has at most 2h distinct outputs, so its mutual information with the training set is bounded:
I(D; S) ≤ H(S) ≤ h · log(2d) + 2h·log k.

3. Reproducibility. Fixed random_state ⇒ S is a deterministic function of (X, P̃, seed) — the accountant can audit the chain without re-running the model.
▌ MINDSET — the tree is a contract
The surrogate is not a "compressed teacher" — it is a declaration of what we are willing to share. Every leaf node is a public statement: "in this hyperrectangle, my data follows this empirical distribution."

Bias as a feature, not a bug. A depth-6 tree cannot encode arbitrary subpopulations — that's the point. Structural under-capacity is a defensive prior against memorisation.

Choose the loss to match the threat. Argmax mode is cheaper and ships smaller blobs — pick it when the federation is bandwidth-constrained. Regression mode is more faithful to KL — pick it when the downstream aggregator wants high-resolution probabilities for proxy redistillation.

The wire format is the API. The aggregator must be able to cls.deserialize(blob) without trusting Client_k's Python environment. So the surrogate's serialised form is the only thing that matters: code-side cleverness that does not survive pickle is invisible.
∎ Surrogate creation invariant: for every Client_k, the artefact Sk = ψ(Xk, P̃k) is (a) a ModelAdapter, (b) εk-DP w.r.t. Dk via post-processing, (c) ≤ MAX_BLOB_BYTES, (d) deterministic given (Xk, P̃k, seed). All four hold or the round fails fast.

Indicator function — 1 if the predicate holds, 0 otherwise. Defines the 0-1 loss.

\(S.\mathrm{proba}(x_i)\)
The surrogate's predicted probability vector at \(x_i\) — element of \(\Delta^{K-1}\). The fit target.
DecisionTreeRegressor.predict(X) with multi-output \(K\)-column targets; row-renormalised at predict time.

Squared \(\ell_2\) (Brier) loss between the privatised target row and the student's output row.
criterion="squared_error" in DecisionTreeRegressor.
