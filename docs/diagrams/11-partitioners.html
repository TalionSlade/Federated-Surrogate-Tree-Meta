Why a sweep across all four matters for the paper

FAIRNESS

FedRF-Distill must beat or match centralised RF on IID — otherwise the method is broken.

NON-IID ROBUSTNESS

Dirichlet sweep (α ∈ {0.1, 0.5, 1.0, ∞}) gives a continuous robustness curve — the gold-standard FL benchmark.

STRESS TEST

Pathological + QuantitySkew expose class-padding and tiny-shard bugs that Dirichlet smooths over.

α
Mathematical Foundation
A single parameter α controls "non-IID-ness"
▌ WHAT — Dirichlet PDF
For each class $c$, draw a $K$-vector $p_c$ from a symmetric $\mathrm{Dir}(\alpha)$. Each entry is the fraction of class $c$ going to client $k$:
$f(p;\alpha) = \dfrac{\Gamma(K\alpha)}{\Gamma(\alpha)^K}\, \prod_{k=1}^{K} p_k^{\alpha-1},\quad p \in \Delta^{K-1}$
$\forall\, c\in\mathcal{C}:\quad p_c \sim \mathrm{Dir}(\alpha\,\mathbf{1}_K),\quad \mathrm{assign}(\mathrm{idx}[c]) \propto p_c$
$\begin{aligned} \alpha &\to 0 &&:\ \text{one-hot} &&\Rightarrow\ \text{pathological} \\ \alpha &= 1 &&:\ \text{uniform} &&\Rightarrow\ \text{moderately non-IID} \\ \alpha &= 0.5 &&:\ \text{standard} &&\Rightarrow\ \text{paper default} \\ \alpha &\to \infty &&:\ \text{equal} &&\Rightarrow\ \text{IID} \end{aligned}$
$\mathrm{KL}\!\left(p_c \;\Big\Vert\; \tfrac{1}{K}\right) \approx \psi(\alpha{+}1) - \psi\!\left(\tfrac{\alpha}{K}{+}1\right) + \log K$
▌ WHY — four partitioners, one sweep
IID is the baseline — proves the federated overhead is small.

Dirichlet is the continuous knob — a sweep over α gives a smooth utility-vs-heterogeneity curve, the FL benchmark gold-standard since McMahan 2017.

Pathological is a discrete worst-case — each client sees only K' classes. Tests the framework's class-padding logic.

QuantitySkew orthogonalises quantity from label distribution — exposes Confidence-Weighted aggregation's strength.
▌ MINDSET — simulate, don't assume
Real federations have no ground truth for "non-IID-ness". Banks' data, hospitals' data, mobile devices — each is its own thing. Dirichlet gives us a quantifiable axis we can sweep at low cost.

Pick the same seed for the partition and the experiment. The framework requires both — same partition seed reproduces shards exactly across runs.

Stratified sampling within Dirichlet draws means the marginal class distribution is preserved — only the conditional per-client distribution skews.

Every symbol in the Dirichlet partition formulas — what it is, where it lives, how it's computed

Symbol
What it represents
Where it lives / how it's computed
Federation cardinality
\(K\)
Number of clients in the federation — also the dimension of each Dirichlet draw.
cfg.federation.n_clients; consumed by data/partitioners.py:DirichletPartitioner.partition().
\(\mathcal{C}\)
Set of class labels — the partition draws one Dirichlet vector per class.
np.unique(y); size n_classes.
\(c\)
A particular class label \(c\in\mathcal{C}\).
Loop variable in DirichletPartitioner._partition_class().
\(k\)
A particular client index \(k\in\{1,\ldots,K\}\).
Indexes into the per-class proportion vector.
The Dirichlet distribution itself
\(\alpha\)
Symmetric Dirichlet concentration parameter — the single knob controlling non-IID-ness.
cfg.partition.alpha; defaults to 0.5 (paper default).
\(p_c\)
\(K\)-vector of per-class allocation fractions; entry \(k\) = share of class \(c\) going to client \(k\).
proportions = rng.dirichlet([alpha]*n_clients) inside _partition_class().
\(p_k\)
A single coordinate of \(p_c\) — the fraction of class \(c\) going to client \(k\).
Single scalar; used as a sampling weight in stratified assignment.
\(\mathbf{1}_K\)
The all-ones \(K\)-vector — the symmetric-Dirichlet concentration tuple is \(\alpha\mathbf{1}_K\).
Implicit in [alpha]*n_clients.
\(\Delta^{K-1}\)
The \((K{-}1)\)-simplex — support of each \(p_c\) (non-negative entries summing to 1).
Verified by assert np.isclose(proportions.sum(), 1.0) in the partitioner.
\(\Gamma(\cdot)\)
The gamma function — appears in the Dirichlet PDF's normalising constant.
Not invoked directly; numpy's Dirichlet sampler handles it internally.
\(f(p;\alpha)\)
Symmetric Dirichlet PDF \(\Gamma(K\alpha)/\Gamma(\alpha)^K\prod p_k^{\alpha-1}\).
Reference PDF; numpy.random.Generator.dirichlet samples from it.
Regime ladder over α
\(\alpha\to 0\)
Concentration collapses to a one-hot — one client takes (nearly) all of class \(c\). Mimics pathological partitioning.
Edge of the supported range in DirichletPartitioner; tested with \(\alpha=0.01\) in regression tests.
\(\alpha = 0.5\)
FedRF-Distill paper default — standard non-IID benchmark.
Default in configs/dirichlet_default.yaml.
\(\alpha = 1\)
Uniform over the simplex — moderately non-IID; each client receives a different but smooth class mix.
Swept value in experiments/scripts/run_benchmark_sweep.py.
\(\alpha\to\infty\)
Concentration sharpens onto the centre of the simplex (\(1/K\)) — IID limit.
Sweep boundary; in practice realised by IIDPartitioner directly rather than huge \(\alpha\).
Distance to IID
\(\mathrm{KL}(p_c\,\Vert\,1/K)\)
Kullback-Leibler divergence between the per-class allocation and the uniform allocation — quantitative "non-IID-ness" axis.
Computed in data/diagnostics.py:partition_kl_to_iid() for each (class, partition) cell.
\(\psi(\cdot)\)
Digamma function — appears in the closed-form expectation of \(\mathrm{KL}\) for Dirichlet draws.
scipy.special.psi; used in the analytic baseline that the empirical KL is sanity-checked against.
From proportions to shards
\(\mathrm{idx}[c]\)
Index set of rows in \((X,y)\) with label \(c\) — the pool stratified-sampled into clients.
idx_c = np.flatnonzero(y == c) inside _partition_class().
\(\mathrm{assign}(\mathrm{idx}[c])\)
Per-class assignment of indices to clients, proportional to \(p_c\).
stratified_assign(idx_c, proportions, rng); respects shard-size minima.
Invariant. Marginalising the per-class assignments over classes preserves the global label distribution — only the conditional per-client distribution skews. A single scalar \(\alpha\) thus indexes a continuous family of partitions from one-hot to uniform.
