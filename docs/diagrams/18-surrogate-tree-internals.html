Under the hood — sklearn.tree._tree.Tree is a struct-of-arrays

A fitted DecisionTreeClassifier is not an object tree in memory — it is a contiguous array-of-structures keyed by node ID (0 = root). Every fitted node populates eight parallel arrays. Understanding this layout is essential because the pickle blob is essentially these arrays: serialise smaller arrays, ship a smaller blob.

feature
int32 (n_nodes,)

Index of the feature tested at each internal node. -2 at leaves.

threshold
float64 (n_nodes,)

Split threshold τ such that x[feature] ≤ τ goes left, otherwise right.

children_left
int32 (n_nodes,)

Node ID of the left child. -1 at leaves.

children_right
int32 (n_nodes,)

Node ID of the right child. -1 at leaves.

value
float64 (n_nodes, 1, k)

Weighted class-count vector at each node. Normalised at leaves to produce predict_proba.

impurity
float64 (n_nodes,)

Gini (or weighted MSE) of the node's training partition after fitting.

n_node_samples
int64 (n_nodes,)

Raw row count reaching the node. Different from weighted_n_node_samples.

weighted_n_node_samples
float64 (n_nodes,)

Σ sample_weight reaching the node — the quantity CART actually optimises over.

CART — greedy weighted impurity minimisation

sklearn's CART builds the tree top-down: at every node, it scans all (feature, threshold) candidates and picks the (j★, τ★) that maximises the weighted impurity reduction Δ𝓘. This is a greedy heuristic — the resulting tree is not globally optimal, but the operation is O(n·d·log n) per level which is the only thing that runs fast enough at scale.

Δ𝓘(j, τ) =   𝓘(P) − (WL/WP)·𝓘(PL) − (WR/WP)·𝓘(PR)

where the partitions are defined by

PL = { i ∈ P : xij ≤ τ }     PR = { i ∈ P : xij > τ }
WL = Σi∈PL wi     WR = WP − WL

Best split chosen by: (j★, τ★) = argmax(j, τ) Δ𝓘(j, τ)

Gini impurity — the metric of choice

For weighted samples in a multiclass setting, the (sample-weighted) Gini impurity of a partition P with class counts (n0, …, nk−1) and proportions pc = nc/WP is:

𝓘Gini(P) = 1 − Σc=0k−1 pc²

Geometric reading: 𝓘Gini(P) is the probability that two random samples from P (drawn proportional to weight) have different classes. Pure node ⇒ 0. Uniform k-class node ⇒ (k−1)/k.

Why Gini over entropy? Computationally cheaper (no logs); produces nearly identical trees in practice. sklearn defaults to Gini precisely because the difference is empirically < 1% accuracy in > 95% of benchmarks while being 2-3× faster.

Inference walk — predict_proba(x) in O(depth)

# sklearn's compiled C walk; the Python equivalent: def predict_proba_row(tree, x): node = 0 while tree.children_left[node] != -1: if x[tree.feature[node]] <= tree.threshold[node]: node = tree.children_left[node] else: node = tree.children_right[node] counts = tree.value[node, 0, :] # (k,) return counts / counts.sum() # π_ℓ # For new point x = (3.5, 3.6): # node 0: x₁=3.5 > 2.40 → right → node 4 # node 4: x₂=3.6 > 2.30 → right → leaf 6 # return value[6, 0, :] / sum = [0, 1.00, 0] → "B" # Predicted: class B with confidence 1.0
# How federation uses this: the surrogate is just # a typed wrapper around the array walk above. class SurrogateAdapter: def __init__(self, tree, classes_): self.tree = tree # sklearn tree self.classes_ = classes_ # global k labels def predict_proba(self, X): # (n, d) → (n, k) return np.stack([ predict_proba_row(self.tree.tree_, x) for x in X ]) def serialize(self) -> bytes: return pickle.dumps(self) @classmethod def deserialize(cls, blob: bytes): return pickle.loads(blob) # conforms to ModelAdapter Protocol → wire-ready

Wire-format anatomy — what's actually inside the ClientUpdate blob?

The pickle byte stream is essentially a compact representation of the sklearn arrays plus metadata. For a depth-6 tree with 32 nodes and k=10 classes, the breakdown is typically:

feature
~128 B
threshold
~256 B
children L/R
~256 B
value (n,1,k)
~2.5 KB
impurity
~256 B
n_samples
~256 B
pickle hdr
~1.5 KB

Total ≈ 5–7 KB for a real-world surrogate; up to ~15 KB at depth 8 with k=20. Compare this to a Random Forest of 100 trees (~500 KB–2 MB raw) — that's the compression ratio of distillation: 50×–200× smaller wire payload while keeping ≥ 90% of the teacher's predictive accuracy on the local distribution.

Mathematical Foundation
CART is a greedy search over a structured hypothesis class
▌ WHAT — the CART recurrence
The fit algorithm is a single recursive function with a base case (purity, depth bound, $\min\_\mathrm{samples}$) and a greedy local optimisation:
$\mathrm{build}(P, \mathrm{depth}) = \begin{cases} \mathrm{leaf}(\hat{\pi}(P)) & \text{if } |P| \le \min\_\mathrm{samples\_leaf} \\ \mathrm{leaf}(\hat{\pi}(P)) & \text{if } \mathrm{depth} = \max\_\mathrm{depth} \\ \mathrm{leaf}(\hat{\pi}(P)) & \text{if } \mathcal{I}(P) = 0 \\ \mathrm{internal}(j^\star,\tau^\star,\, \mathrm{build}(P_L,\mathrm{d}{+}1),\, \mathrm{build}(P_R,\mathrm{d}{+}1)) & \text{otherwise} \end{cases}$
$(j^\star,\tau^\star) = \arg\max_{(j,\tau)} \Delta\mathcal{I}(P, j, \tau),\quad (P_L,P_R) = \mathrm{partition}(P,j^\star,\tau^\star)$
$\Delta\mathcal{I}(j,\tau) = \mathcal{I}(P) - \dfrac{W_L}{W_P}\,\mathcal{I}(P_L) - \dfrac{W_R}{W_P}\,\mathcal{I}(P_R)$
$\mathcal{I}_{\mathrm{Gini}}(P) = 1 - \sum_{c=0}^{K-1} p_c^{2},\quad p_c = \dfrac{n_c}{W_P}$
$\hat{\pi}(P) = \left(\dfrac{\sum_{i\in P} w_i\, \mathbf{1}\{y_i=c\}}{W_P}\right)_{c=0,\ldots,K-1} \in \Delta^{K-1}$
# total fit: $O(n\,d\,\log n \cdot 2^{h})$
▌ WHY — three properties for free
The CART surrogate gives us three properties simultaneously that no other simple model class delivers:

1. Axis-aligned interpretability. Every internal node is a single inequality x[j★] ≤ τ★ — auditable by a human, debuggable in three lines of Python. A DP analyst can read the tree and ask "is this split disclosing anything sensitive?"

2. Native sample weighting. Both the Gini impurity and the leaf prediction use the same weighted denominator WP. The teacher's confidence vector P̃ ↦ (ŷ, w) is the only place w enters — beyond that, sklearn handles it. No retrofitting, no loss surgery.

3. Bounded output space. A depth-h tree has at most 2h distinct outputs. Aggregators can enumerate them — the proxy redistillation step relies on this finite-image property.
▌ MINDSET — greedy is good enough
Optimal decision-tree learning is NP-hard. Hyafil-Rivest (1976) proved it; nothing in 50 years has dethroned the result. So all production-grade DT learners are greedy heuristics — sklearn is no exception, neither is XGBoost, neither is LightGBM.

But greediness aligns with our threat model. A globally optimal tree would over-fit to subtle interactions between features — the same interactions that fuel membership-inference attacks. A greedy myopic tree can't see those interactions and is therefore structurally more private by construction.

The greedy split is the contract. Every (j★, τ★) becomes a row in the wire format. Designing CART around what we can cheaply ship over a network — not around what is statistically optimal — is the unstated discipline of federated learning.

Reproducibility > performance. A 0.5% accuracy gain isn't worth a non-deterministic build. random_state is fixed because the accountant needs to replay the round; CART must be a pure function of (X, P̃, seed, hyperparams).
∎ Internals invariant: for every fitted surrogate tree.tree_, the eight parallel arrays satisfy: (1) feature[i] ∈ [-2, d); (2) children_left[i] = -1 ⟺ children_right[i] = -1; (3) weighted_n_node_samples[parent] = weighted_n_node_samples[left] + weighted_n_node_samples[right]; (4) value[i] is non-negative and normalises to πi ∈ Δk−1.

\(K\)
Number of classes — width of the leaf probability vector.

Empirical class distribution stored at the leaf — \((n_0/W_P,\dots,n_{K-1}/W_P)\); element of \(\Delta^{K-1}\).

Probability simplex on \(K\) classes — the codomain of every \(\hat\pi(P)\) and of predict_proba.

Note. The four base/recursive cases plus the greedy \((j^\star,\tau^\star)\) selection plus the leaf summariser \(\hat\pi\) constitute the entire fit pipeline. Because every quantity is a deterministic function of \((X, \tilde P, \mathrm{seed}, \mathrm{hyperparams})\), the resulting tree_ arrays are bit-reproducible — which is what the privacy accountant needs to replay a round.
